## How it works

Run `main.py` with the output directory set in the environment variable
named MAKEFUN_OUTPUT_DIR. The program validates the joke (non-blank,
single line, 1 to 200 characters) and writes it to `entry.txt` in that
directory, UTF-8 encoded with no trailing newline.

## Usage

    python3 main.py

with MAKEFUN_OUTPUT_DIR pointing at the desired output folder.
